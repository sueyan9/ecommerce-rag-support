Local-First Clinic RAG

Clinic support answers, grounded in your SaaS knowledge base.

This demo shows a lightweight clinic management support assistant built with FastAPI, Qdrant, and Ollama. Ask a product or policy question and the app retrieves the most relevant clinic support context before generating an answer.

FastAPI API for ingestion, retrieval, and support answers
Qdrant Semantic search over clinic knowledge chunks
Ollama Local models for embeddings and answer generation
