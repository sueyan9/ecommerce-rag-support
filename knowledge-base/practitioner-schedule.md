# Practitioner Schedule

Practitioner schedules in this demo knowledge base are managed at the branch and service level.

## Availability rules

Each practitioner can have recurring weekly availability plus ad hoc overrides for leave, training, or branch transfer. Overrides always take priority over the recurring template.

## Multi-branch work

When a practitioner works across two branches, each time block should be assigned to only one branch. The system should not allow overlapping confirmed appointments across different branches.

## Booking safeguards

Staff should review travel gaps when moving a practitioner between branches on the same day. Schedule conflicts must be resolved before confirming a booking.
