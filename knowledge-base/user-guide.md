# Clinic User Guide

This demo clinic platform helps front-desk staff, practitioners, and branch managers handle day-to-day operations in one system.

## Main modules

- Dashboard for daily activity and pending tasks
- Appointments for booking, rescheduling, and cancellations
- Practitioners for availability and service assignment
- Branches for location-specific configuration
- Billing for invoices and payment tracking
- Settings for pricing, permissions, and privacy controls

## Support notes

Users should search for the patient record before creating a new booking to avoid duplicate profiles. Sensitive notes should be entered only in fields marked for internal operational use.

Branch managers can view activity for their own branch by default. Organization admins can work across all configured branches.
