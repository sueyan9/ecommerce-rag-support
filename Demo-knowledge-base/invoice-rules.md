# Invoice Rules

Invoices in this demo system are created from completed appointments or approved manual billing entries.

## Required fields

An invoice must include branch, practitioner, service line, fee amount, and billing status before it can be finalized.

## Editing rules

Draft invoices can be edited freely by authorized billing staff. Finalized invoices require a correction workflow instead of direct field edits.

## Cross-branch billing

If a practitioner works at multiple branches, the invoice should be attached to the branch where the service was delivered. The invoice prefix should follow the branch configuration.
