# Branch Management

This demo clinic SaaS supports multiple branches under one organization account.

## Branch setup

Each branch can maintain its own operating hours, contact details, appointment rooms, and invoice prefix. Branch managers can edit branch-level settings but cannot change organization-wide billing policies.

## Access model

Users are assigned a primary branch and a role. Organization admins can access all branches. Branch managers can access only branches they are assigned to.

## Reporting

Operational reports can be filtered by branch, practitioner, and date range. Cross-branch reports should be reviewed by an organization admin when billing or pricing disputes are involved.
